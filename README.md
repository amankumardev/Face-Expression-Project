🎭 AI Face Expression Detection System

Real-Time Emotion Recognition using Computer Vision & Deep Learning


📌 Overview

The AI Face Expression Detection System is a real-time emotion recognition application that detects human facial expressions using a webcam.
It uses Computer Vision and Deep Learning techniques to analyze facial features and predict emotions such as:

😄 Happy

😢 Sad

😠 Angry

😲 Surprise

😐 Neutral

😨 Fear

🤢 Disgust

This project demonstrates practical implementation of AI concepts in real-world scenarios.

🚀 Features

✔ Real-time face detection
✔ Emotion recognition using FER library
✔ Live webcam analysis
✔ Bounding box with emotion label
✔ Clean & simple Python implementation
✔ Beginner-friendly and extendable

🛠️ Technologies Used

Python 3

OpenCV

FER (Facial Emotion Recognition)

NumPy

Deep Learning Concepts

⚙️ Installation & Setup
1️⃣ Clone the Repository
(https://github.com/amankumardev/Face-Expression-Project)
2️⃣ Install Dependencies
pip install -r requirements.txt

Or manually:

pip install opencv-python fer numpy
3️⃣ Run the Project
python main.py

Make sure your webcam is connected.

🧠 How It Works

Webcam captures real-time video.

OpenCV detects faces in each frame.

FER model analyzes facial features.

The system predicts emotion.

Emotion label is displayed on the screen.
